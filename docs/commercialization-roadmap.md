# Commercialization roadmap

This page is a roadmap. None of it is implemented in Phase 1, and none of it is evidence of demand.

REWIND is intended to become software that operators can install and rely on for uncertain MCP side effects. Phase 1 is the correctness foundation: protocol behavior, a durable journal, and explicit limits.

Possible later directions, not commitments:

- A self-hosted build aimed at a single team
- Organization deployment and support
- Licensing terms beyond the Apache-2.0 grant in this repository
- Stronger audit export
- More transports
- A hosted service only if there is a separate decision to build one

Not in Phase 1: billing, subscriptions, license enforcement, tenant isolation, a control plane, or a dashboard.

Recovery and reconciliation are later product phases. They are not started here, and this roadmap does not set a price or a readiness date.
